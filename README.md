# Simple Web Calculator

A sleek, responsive web calculator built with HTML, CSS, and JavaScript. Features an animated gradient background, glassmorphism container, and dynamic motion effects.

## 🚀 Live Demo
You can access the live app here:
https://ekbiharii.github.io/web-calculator/

---

## ✨ Features
- **Core Operations:** Addition, Subtraction, Multiplication, and Division.
- **Dynamic Background:** Smooth continuous gradient animation shifting through vibrant colors.
- **Glassmorphism UI:** Semi-transparent dark shell with background backdrop blur.
- **Interactive Motion:** Hover elevations, soft button click feedback, and subtle container floating motion.
- **Responsive Layout:** CSS Grid layout optimized for mobile and desktop screens.

---

## 🛠️ Tech Stack
- **HTML5:** Semantic structural layout.
- **CSS3:** Animations, Keyframes, Flexbox, and CSS Grid.
- **JavaScript:** Calculator logic and input handling.
